## Route / guard matrisi

| Yöntem ve yol | Yetki / guard |
| --- | --- |
| POST `/api/auth/signup`, `/login`, `/logout`, `/recovery`, `/confirm`; PUT `/api/auth/password` | Exact application Origin + double-submit CSRF; ardından mevcut Auth akışı |
| POST `/api/businesses`, `/api/businesses/select` | Aynı guard; güncel kullanıcı/üyelik |
| POST `/api/services`, `/api/staff`; PATCH her ikisinin `/:id` yolu; PUT `/api/staff/:staffId/services/:serviceId` | Aynı guard; güncel üyelik/rol |
| POST `/api/bookings`, `/:id/reschedule`, `/:id/status` | Aynı guard; üyelik ve mevcut booking/idempotency kuralları |
| PUT `/api/availability/business-hours/:weekday`, `/api/availability/staff/:staffId/hours/:weekday`; POST `/api/availability/blocks`; DELETE `/api/availability/blocks/:id` | Aynı guard; üyelik/rol |
| PUT `/api/public/settings` | Cookie-auth; public istisnası değildir |
| POST `/api/public/business/:slug/book`, `/api/public/booking/recover` | Dar public istisna; abuse/proof/idempotency korunur |
| POST `/api/manage/view`, `/slots`, `/reschedule`, `/cancel` | Dar capability istisna; token yalnız body'de, mevcut doğrulama/tekrar kuralları korunur |
| Diğer unsafe `/api/*` | Varsayılan cookie guard; benzer yol veya farklı yöntem istisna kazanmaz |
| GET / HEAD / OPTIONS | Mutation guard yok; gerekli yerde auth devam eder |
| Scheduled dispatcher | HTTP router dışındadır |

`Origin` ve `Sec-Fetch-Site` eksikliği izin vermez. Exact Origin geçerliyken Sec-Fetch-Site zorunlu değildir; cross-site değeri reddedilir. Geçerli Origin + eksik/yanlış CSRF reddedilir. 21 cookie mutation ve 6 POST istisnası testte gerçek mounted handler envanteriyle karşılaştırılır.

| Durum | Sonuç |
| --- | --- |
| Geçersiz, yenilenemeyen session | 401 AUTH_REQUIRED; geçersiz session temizlenir |
| Seçili aktif üyelik yok/iptal edilmiş | 403 TENANT_REQUIRED; access/refresh korunur, geçersiz işletme seçimi kaldırılır |
| Başka işletmeyi seçmeye yetki yok | 403 TENANT_FORBIDDEN; mevcut seçim korunur |
| Auth, refresh veya üyelik sağlayıcısında 5xx/ağ hatası | 503 AUTH_UNAVAILABLE; mevcut session/seçim cookie'leri korunur |
| Recovery session feature API'sine gider | 403 PASSWORD_UPDATE_REQUIRED; S01 sınırı korunur |

Domain RPC hataları bu auth hata tablosuna zorla çevrilmez; iş hata sözleşmesi korunur. Sentetik Cookie/Origin isteği gerçek tarayıcı CSRF saldırısı kanıtı diye raporlanmaz.
