# F17-01 devir — geliştirme ve staging ortamı

Durum: **Repo-side hazırlık tamamlandı; canlı kabul açık.** Bu görev, gerçek Randevu staging hesap/secret erişimi doğrulanmadan `Tamamlandı` sayılmaz.

## Repo tarafında hazır olanlar

- Cloudflare `staging` environment sözleşmesi ve `npm run build:staging`.
- Manual `Staging deploy` GitHub Actions workflow'u.
- Supabase migration push sırası.
- Server-side test Auth owner bootstrap'ı.
- İki sahte işletmeli tenant-safe staging fixture, reset ve acceptance SQL'i.
- Notification/public-booking server secret hash provisioning.
- Gerçek Worker API zinciri için staging smoke: health → login → session → business select → catalog.
- Secret değerleri repo/PR/handoff içine yazılmaz; workflow yalnız secret isimlerini sözleşme olarak taşır.

## Canlı kabul için gerekenler

1. Production'dan ayrı, doğrulanmış bir **Randevu Supabase staging projesi**.
2. GitHub `staging` environment altında runbook'taki Supabase/Cloudflare/runtime secret adlarının tanımlanması.
3. Cloudflare hesabında staging Worker deploy erişimi ve gerçek HTTPS `STAGING_APP_ORIGIN`.
4. Supabase Auth Site URL / redirect allowlist'in staging origin'e ayarlanması.
5. Staging'e ait gerçek Resend erişimi ve doğrulanmış test sender/subdomain.
6. `Staging deploy` workflow'unun gerçek hesaplarla yeşil tamamlanması.
7. Smoke sonucunda iki sahte tenant'tan en az biriyle gerçek Auth login + session + catalog zincirinin geçmesi.

## Güvenlik ve veri sınırı

- Production müşteri/personel verisi fixture'a kopyalanmaz.
- `SUPABASE_ADMIN_KEY` yalnız workflow'da test Auth kullanıcılarını hazırlamak için kullanılır; Worker runtime'a verilmez.
- `PUBLIC_BOOKING_GATE_SECRET` ve `NOTIFICATION_DISPATCH_SECRET` raw olarak DB'ye yazılmaz; DB yalnız SHA-256 hash tutar.
- Management link encryption key, provider key ve test kullanıcı parolaları Git/PR/handoff'a yazılmaz.
- Yeni Supabase projelerinde Data API auto-exposure davranışına güvenilmez; repo migration'larındaki explicit `GRANT` + RLS sınırı korunur ve staging smoke ile doğrulanır.
