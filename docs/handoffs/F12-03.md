## Ürün yüzeyi

F12-03 accepted F10-04 katalog motorunu ikinci bir katalog sistemi kurmadan dar biçimde genişletir.

Hizmet artık şu canonical alanları taşır:
- `category`
- `sort_order`
- `price_type = fixed | range`
- `price_min_minor`
- `price_max_minor`
- `currency`
- `price_policy_version`

Katalog editorü kategori, sıralama ve fixed/range fiyat girişini yönetir. Fixed fiyat için lower=upper değişmezi korunur. Range fiyat katalogda yönetilebilir ancak F11/F12-04 range-aware booking capability gelmeden mevcut tek-fiyatlı booking yüzeyi bu hizmeti yeni randevu için seçilebilir göstermez.

## Veri ve para sözleşmesi

Ana forward migration: `supabase/migrations/20260915150000_f12_service_price_range.sql`.

Değişmezler:
- tüm parasal değerler **integer minor-unit**;
- JS float veya client-side toplam finansal authority değildir;
- FX / currency conversion yoktur;
- `fixed` için `price_min_minor = price_max_minor`;
- `range` için `0 <= min <= max`;
- canonical compatibility mirror `price_minor = price_min_minor` olarak kalır;
- legacy fixed kayıtlar migration sırasında kayıpsız `min=max=price_minor`, `price_type=fixed`, `price_policy_version=1` olur;
- fiyat/type/currency değişimi `price_policy_version` değerini artırır;
- mevcut appointment snapshotları migration veya katalog editleri tarafından rewrite edilmez;
- `price_minor` bir range hizmetin kesin tahsilat tutarı değildir.

Input fail-closed kuralları:
- negatif fiyat reddedilir;
- min > max reddedilir;
- fixed fakat min != max reddedilir;
- üç-harf canonical currency shape dışı değer reddedilir;
- mixed-currency server estimate reddedilir;
- cross-tenant/inactive/missing service estimate fail-closed kalır.

## Server-authoritative estimate

`f12_price_estimate_internal(uuid, uuid[])` en fazla 10 ordered service id için şu frozen-shape'i üretir:
- `currency`
- `lower_minor`
- `upper_minor`
- ordered `lines`
- her line içinde `serviceId`, `priceType`, `lowerMinor`, `upperMinor`, `currency`, `pricePolicyVersion`.

Bu çıktı **estimate**'tir, charge/ledger/payment değildir. Range lower/upper toplamının kesin satış veya tahsilat olduğu varsayılamaz.

Mixed currency fail-closed `CURRENCY_MISMATCH`; inactive/missing/cross-tenant seçim `SERVICE_NOT_FOUND` ile kapanır.

## Legacy booking ve public fail-closed sınırı

Eski public service projection tek `price_minor` taşıdığı için yalnız `fixed` hizmetleri yayınlar. Range lower bound hiçbir public/customer yüzeyinde kesin fiyatmış gibi gösterilmez.

Eski appointment tablosu tek definitive `price_minor_snapshot` taşıdığı için F12-03 range hizmetin bu eski snapshot modeline girmesini engeller:
- DB trigger: `appointments_f12_fixed_price_guard`
- deterministic error: `SERVICE_PRICE_NOT_FINAL`
- Worker mapping: HTTP 409
- operator `BookingPage`: yeni create seçicisinde yalnız fixed hizmetler.

Bu guard F11 group/service-line snapshot modeli geldiğinde o yeni model tarafından bilinçli biçimde değiştirilecektir; F12-03 range hizmeti eski tek-fiyatlı appointment alanına zorla sığdırmaz.
