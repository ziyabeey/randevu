## Güvenlik ve davranış

- Session bearer'ları yalnız HttpOnly cookie'de tutulur; API cevabına, URL query/fragment'ına veya loglara yazılmaz.
- Geçersiz access cookie gerçek refresh tokenla yenilenir; başarısız yenilemede session/business/recovery cookie'leri temizlenir.
- Aktif işletme üyeliği cookie iddiasından değil güncel `memberships` kaydından doğrulanır; pasif/silinmiş üyelik seçili işletmeyi düşürür.
- Browser mutation'ları exact same-origin, `Sec-Fetch-Site` ve double-submit CSRF kontrolünden geçer.
- Signup/recovery PKCE verifier kısa ömürlü ve bounded HttpOnly flow cookie'sinde kalır; auth code server-side değiştirilir, state/token replay reddedilir.
- Yanlış, süresi dolmuş veya tekrar kullanılmış doğrulama bağlantıları generic `AUTH_LINK_INVALID` cevabına düşer.
- Recovery oturumu session, logout ve password update dışında işletme/randevu feature API'lerine giremez; kontrol tenant lookup'tan önce `PASSWORD_UPDATE_REQUIRED` döndürür.
- Parola güncellemesi global sign-out çağrısını dener ve yerel session'ı kesin olarak temizler.
