## Measurement decision

The saved suite observation is the root for coverage and any test-result facts
derived from that invocation. The collection's bounded pre-execution source audit
is a separate static observation; it did not consume TAP/V8. Dependency facts
retain that whole original audit digest, never a new digest per metric/edge.
Its eleven source files all belong to refrozen development. The complete closure
also includes evaluation inputs and is used for split verification only, not as
a fact root. Its six production importers are not the bounded fact's denominator.
Shared source revision identifies the subject, not a new independent measurement.
M9's disjoint-observation-root count is not statistical independence of the facts,
anchors, repository components or eventual assessor judgments. No common runtime
or configuration binding becomes a standalone evidence family.

Baseline packets have no changed files and cannot authorize narrowing. Only
observed uncalled named V8 entries yield explicit suite-scoped gap hypotheses.
Source-text UI checks retain unknown/null coverage and produce no change-impact
hypothesis without actual impact observations.
